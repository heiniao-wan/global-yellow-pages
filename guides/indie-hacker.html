一个人做产品出海，中间隔着建站、开发、设计、文案、合规好几道坎。这份合辑把这条动线上的关键站点串成一条线：代码放哪里、部署去哪里、图片从哪来、文案怎么翻。每一个都有免费额度，零预算就能起步；等产品开始赚钱，再考虑升级付费计划。顺序也基本是按开发流程排的——照着走一遍，比零散收藏一堆教程管用。

写代码

代码放对地方，协作和版本管理才有地基

  1. GitHub

    代码托管与开源协作的门票。独立开发者的技术信用攒在这里，Star 数就是硬通货，也是后续所有 CI 和部署的地基。

    全球最大代码托管平台，承载开源项目协作与软件包分发。

    开发全球英文

  2. Cursor

    AI 原生编辑器，一个人干一个前端团队的活。对独立开发者来说，省下的不只是时间，是请不起人的成本。

    AI 优先的代码编辑器，支持对话式改码与整仓上下文理解。

    AI欧美英文

  3. GitHub Copilot

    补全与问答两用的编程副驾，和 GitHub 账户体系打通，私有仓库里也能用。

    主流 AI 编程助手，在编辑器内补全代码、生成函数并解释逻辑。

    AI全球多语言

部署与基础设施

前端上 Vercel，域名和 DNS 交给 Cloudflare，其余先租最便宜的 VPS

  1. Vercel

    前端部署的事实标准，Git 推上去就自动构建上线，免费额度对早期项目完全够用。

    前端云部署平台，对 Next.js 框架的预览与托管支持完善。

    开发欧美英文

  2. Cloudflare

    DNS、CDN、SSL 到 Workers 一条龙。出海产品的第一道门面就该挂在这里，抗打且免费档不含糊。

    全球 CDN 与云安全服务商，提供加速、DDoS 防护与边缘计算。

    开发全球英文

  3. Namecheap

    域名注册商里价格和口碑平衡得最好的一家，隐私保护默认送，续费不玩套路。

    域名注册与 DNS 托管服务商，价格透明且支持多币种支付。

    开发全球英文

  4. DigitalOcean

    VPS 起点：文档是全行业最好的，按月付、随时删。等流量起来了再迁也不迟。

    面向开发者的云服务器厂商，VPS 与托管数据库易于上手。

    开发欧美英文

  5. npm

    前端生态的包仓库。找轮子先来这里，发布自己的包也是在这里完成第一次「上线」。

    JavaScript 最大包管理仓库，海量前端与 Node 依赖可直接获取。

    开发全球英文

设计与素材

不请设计师，也能让产品不像草台班子

  1. Figma

    界面设计的事实标准，免费档够个人用。它的社区模板还能直接扒来做原型。

    浏览器端界面设计协作工具，UI 设计行业团队使用率极高。

    工具全球英文

  2. Canva

    不会 PS 也能出图：落地页配图、社交媒体横幅、简单的图标排版，模板套一套就有模有样。

    全球化在线设计工具，模板生态与协作功能让非专业创作者上手。

    工具全球多语言

  3. Pexels

    免费可商用的图库视频，出海产品再也不用担心版权律师函。质量比大多数付费图库还高。

    免费图片与视频素材平台，内容数量庞大且无需注册可用。

    工具全球多语言

  4. Unsplash

    另一个免费图库，偏摄影质感。产品官网的 hero 背景图很多就出自这里。

    免费高清图片素材库，摄影师免费发布且商用授权宽松。

    工具全球英文

效率与文案

最后两公里：把东西写清楚，把资料管起来

  1. Notion

    一个人的指挥部：需求文档、发布清单、用户反馈全塞进去。出海项目的「办公室」。

    模块化笔记与知识管理工具，文档数据库一体化协作广泛使用。

    工具全球多语言

  2. DeepL

    产品文案英翻中的默认选项，也能反向用。做多语言落地页时，它的语气比机翻自然一个档。

    以译文自然度著称的 AI 翻译工具，支持整篇文档与原网页翻译。

    AI欧美多语言
