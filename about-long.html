关于本站

写给第一次来这里的人，也写给想弄清楚「这站到底靠不靠谱」的人。
顺便说一句：这篇文章是手写的，不是模板生成的。

一、我为什么做这个站

起因很小。

去年我想找一个能把 PDF 转成可编辑 Word、并且不把文件传到第三方服务器的工具。

搜索的过程是这样的：搜"PDF转Word 在线"，前五条全是广告，界面一个比一个像病毒；换词搜"隐私版"，出来的是一堆软文，每篇都在推同一个产品；再往后只能一个一个点进去试。试到第五个的时候，我意识到真正卡住我的不是搜索能力——

是没有任何办法判断这些网站到底靠不靠谱。

界面试了就知道丑不丑，但"它会不会偷偷把我要处理的文件传走"这件事，试十次也试不出来。搜索结果给的是"最佳答案"，而我需要的是"真实用过的人怎么说"。

那段时间我意识到一个更普遍的问题：一个人验证过的信息，对另一个人是零成本的。 我花两小时确认一个工具靠不靠谱，你完全不必再花两小时。可这些验证结果没有出口——没有地方能沉淀下来。

于是我做了这个站。

二、它是什么

全球黄页是一个按行业分类整理的优质网站导航库，收录全球各行业的知名站点，目前 381 个站点、17 个行业分类。

它提供三件事：

第一，按行业浏览和关键词搜索。 分类体系参考主流流量分析平台（Similarweb、Ahrefs 一类）的通用行业划分，不是拍脑袋定的。AI 与大模型那一栏有 62 个站点，机械制造有 32 个——数量差异反映的是生态本身的差异，不是我的偏好。

第二，首页截图。 每个站点都有自动抓取的首页缩略图。这一点看起来是锦上添花，实际上很关键：一个工具的官网首页长什么样，常常直接决定了它靠不靠谱。打开就是一张大图加"联系我们"的，多半不是你想要的。

第三，真实用户投票。 每个站点三档：👍 好用、👎 一般、🚫 无法访问。第三个按钮是整个设计的核心，下面单独说。

三、我做的几个具体决定

1. 「无法访问」比五星评分更有用

五星评分的问题是中间态太模糊——3 分和 4 分的区别没人说得清。

而"打不开了"是一个客观的、可验证的事实。你收藏过某个网站，2026 年再访问发现域名已经被 SEO 农场接管了——这种事在普通导航站上几乎无法察觉，因为站长自己可能都不知道。

「无法访问」这个按钮把这件事变成了每个访问者都在替所有人做侦察。任何一个人点下去，统计里的红色就多一分，全站所有人都能看到。这不是站长一个人在把关，是所有访问者一起。

2. 不注册也能投票

很多导航站要求注册才让投票，理由是"防止刷票"。但注册本身就是极高的流失门槛——90% 的人看到要注册就走了。那这 90% 人的真实反馈就此丢失，那个投票数据也就失去了意义。

我的选择是：门槛降到零，用技术手段而非门槛来防刷。

具体怎么做的，见下面第四节。

3. 票可以取消，也可以改

最初的版本我写的是"一票定终身"，因为怕刷票。结果用户反馈很直接：投错了怎么办？打不开了想撤回怎么办？

现在改成了"一站一票"——同一个站点只保留一票，但这票可以撤销、可以改选。而且约束从"前端拦截"升级成了"服务端强制"：不是靠 JS 拦着你不让你点第二下，而是服务器真的只认一票。

这个改动是我做的所有改动里最被认可的一个。

4. 隐私上的取舍

有一件事我必须说清楚，因为它和常见做法不一样。

浏览器的设备指纹（Canvas 指纹、时区、硬件特征这些）是很稳定的，等同于个人标识。如果直接存进数据库，数据库里就躺着可关联到具体设备的数据。

所以我做了一个处理：指纹在发送到服务器前，先用只有站长掌握的密钥做一次不可逆的哈希。 服务器和数据库里保存的都只是哈希值，看不到指纹原文，也没有任何办法由哈希值反推回你的设备。

代价是诚实的：换掉那把密钥，所有人的历史投票记录就"失联"了（因为键名里的哈希变了）。所以这个值定下来就没再动过。

另外一个决定：站长的邮箱是公开的（Huoyld@163.com），而留言者的联系方式是不公开的。留言只进站长的后台，够用、能回复、不会被翻出来。这个方向我认为是反的，但它是站长的权利。

四、怎么防止刷票

分两层。

本地层（第一道过滤） 在浏览器里跑，六个信号：

  • 蜜罐字段——真人看不见的隐藏输入框，自动化脚本按表单扫描时会填
  • 交互时序——页面加载到点击的间隔，快于人类反应极限直接拦
  • 设备指纹——Canvas 指纹 + 硬件特征 + 时区 + WebGL 渲染器
  • 速率限制——滑动窗口内每分钟最多 20 次
  • 一站一票——指纹 × 站点 ID 联合唯一键
  • 存活性检测——后台标签页里的投票不予采信

服务端层（真正的强制） 在 Cloudflare 的边缘函数里：

  • 同一指纹对同一站点只保留一票，改票是"撤旧 + 加新"，不是叠加
  • 每分钟 20 次写操作上限（按身份算）
  • 每分钟 60 次上限（按出口 IP 算，防一人多指纹）
  • 参数白名单校验，站点 ID 只允许安全字符，防键注入
  • 蜜罐有值直接 403

我也要说清楚这套东西的边界： 它挡得住随手刷和普通脚本，挡不住有耐心的专业刷票方——他们可以伪造浏览器指纹。要根治得上验证码或登录验证，我刻意没做，因为那会把这个站最核心的"零门槛"毁掉。

这是个明确的取舍，不是没考虑到。

五、数据是怎么来的

站点数据是逐个核对官网整理的，不是从某个目录站批量抓的。每条包含：官网 URL、中文简介（一句话，说明它到底提供什么）、所属分类、地区、界面语言。

分类体系参考主流流量分析平台的通用行业划分，这样跟你在别处看到的分类能对得上。

投票数据来自访问者，实时汇总，全站共享。

截图由第三方服务自动抓取（Microlink、WordPress mShots），首页加载时滚动到视口内才请求，不是全量预加载。

六、收录标准

三条，缺一不可：

确实有用。 不是空壳站，不是纯广告站，不是"XX 教程"类内容农场。有实际功能、有人在用。

相对可靠。 公司主体清晰、有实际业务、能查到联系方式。做机械制造那一栏时我加了一条硬标准：得在全球有服务网点——说明它是真的在卖设备，不只是做贸易。

全球可访问。 有能正常打开的国际域名和页面。

同质化严重的我会择优留一个。比如设计类里有大量素材站，版权风险和可用性差异很大，我留的是授权条款清楚、导出可直接用于真实工作的那批。

七、这个站不做什么

说清楚边界比夸大功能有用。

不做推荐。 金融那一栏我只收交易所、监管机构、一级数据渠道，任何以"推荐买入""翻倍牛股"为卖点的站点一律不收，无论它看起来多热门。站内的投票只反映"这个站点是否值得一用"，跟投资判断无关。

不替第三方站点背书。 本站与所收录的任何网站均无隶属、投资或合作关系。收录本身不构成推荐或担保。

不提供专业建议。 健康那一栏我只放有专业资质背书的机构官网，并且会提醒：任何疾病的具体诊疗方案都应当面诊，网上内容只适合做常识了解。

不收集身份信息。 不注册、不要求手机号、不做用户画像。

八、技术实现

纯静态站，部署在 Cloudflare Pages，代码完全自有。

  • 前端：原生 JS，无框架。两个皮肤版本（index.html 苹果风、index-v2.html 未来科技感），共用同一份数据与交互逻辑
  • 数据：data.js 单一数据源，改数据后重跑生成脚本，SEO 基建（sitemap、静态索引页、分类页、OG 图）自动同步
  • 服务端：Cloudflare Pages Functions + KV 存储，承载投票与留言
  • 无追踪：本站自身不设跟踪 Cookie
  • PWA：可添加到主屏，离线可读已访问过的页面
  • 四语：中英日韩，切换后分类名、投票标签、统计图表、FAQ 全部同步翻译

关于搜索引擎可见性，我踩过一个坑值得记下来：首页的站点列表原本靠 JS 渲染，爬虫抓到的原始 HTML 里一个站点都看不到、也没有任何出站链接。后来我把 36 个代表站点直接写进了静态 HTML，爬虫视角的可见内容从 131 词涨到近 2000 词、外链从 0 变成 36 个。这是给爬虫看的，也是给禁用 JS 的用户看的——两者都需要。

九、怎么参与

投票。 这是最有价值的参与方式。如果你发现某个站点打不开了，投一票"无法访问"——这一票能帮到后面所有看到它的人。如果你觉得某个工具好用，👍 一下同样是真实反馈。

推荐站点。 页面底部有反馈表单，留下网址和一种联系方式（电话或邮箱都行），我核实后就会加入目录。

提意见。 哪些分类该加、哪个站点介绍写得不对、哪个功能难用，都欢迎说。

十、最后

如果这个站确实帮到过你——哪怕只是让你少踩一次坑——那它就没白做。

如果你觉得某个地方做得不对，直接说。我宁可听到难听的实话，也不想看到一个漂亮但没用的导航站。
